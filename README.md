
# ColabMapsApp

This is the initial setup for ColabMapsApp, a web application designed for mobile and desktop access, running in Docker containers, and using GitHub for version control with manual Firebase deployment.

## Project Structure

- `webapp/`: Contains frontend files (HTML, CSS, JavaScript).
- `backend/`: Contains the Python Flask backend application and its dependencies.
- `configs/`: Stores configuration files for Docker and Firebase.
